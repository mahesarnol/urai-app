Urai App 3.0 adalah versi pertama dengan nama baru dan tampilan baru.

## Yang baru

- Tampilan baru dengan alur tiga langkah: Dokumen, Atur hasil, Selesai. Tema terang dan gelap mengikuti Windows.
- Tarik file atau folder ke mana saja di jendela. Tersedia juga di menu klik kanan **Kirim ke**.
- Pilih satu file per dokumen, atau gabung semua jadi satu file dengan urutan yang bisa diatur.
- Baca PDF hasil scan dan gambar tanpa internet (Tesseract OCR): bahasa Indonesia, Inggris, Jawa, Sunda, dan Arab. PDF hasil scan dikenali otomatis.
- Mode AI dengan API key Anda sendiri: Claude, Gemini, DeepSeek, OpenAI, OpenRouter, atau server lain.
- Mind map dari struktur dokumen (offline) atau rangkuman AI (Umum, Notulen, Laporan), bisa disimpan sebagai PDF (A4, A3, F4), PNG, HTML, atau Markdown.
- Halaman Tentang dengan daftar lisensi, halaman Panduan, dan tombol Dukung.

## Eksperimental

Transkrip YouTube dan rekaman suara ke teks. Keduanya bergantung pada layanan pihak ketiga yang bisa berubah sewaktu-waktu.

## Memasang

Unduh `UraiApp-3.0.0-Setup.exe` di bawah, lalu jalankan. Bila muncul "Windows melindungi PC Anda", tekan **Info selengkapnya › Tetap jalankan**. Versi tanpa pasang: `UraiApp-3.0.0-portable.zip`. Sidik jari SHA-256 ada di `SHA256SUMS.txt`.

Urai App versi lama (MarkItDown untuk Windows 1.x/2.x) sebaiknya dicopot lebih dulu lewat `Uninstall.bat` di folder pemasangannya.
