Letakkan gambar QRIS GoPay Merchant di folder ini dengan nama qris.png.

- Unduh QRIS dari aplikasi GoPay Merchant (menu QRIS > Unduh/Simpan QRIS).
- Potong supaya hanya kotak kode QR beserta nama merchant yang terlihat, ukuran sekitar 600 x 600 piksel.
- Simpan sebagai qris.png di folder ini, lalu rakit ulang aplikasinya.

Selama file ini belum ada, jendela Dukung menampilkan tempat QRIS dengan tulisan "QRIS resmi menyusul",
dan ajakan dukungan di panel hasil tidak ditampilkan.
