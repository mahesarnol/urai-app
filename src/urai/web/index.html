      Panduan singkat

      Tiga langkah, dari dokumen sampai file Markdown.

      1. Tambahkan dokumenTarik file atau folder dari File Explorer ke jendela ini, atau tekan tombol File dan Folder. Link YouTube dan halaman web ditempel di kolom paling bawah, lalu tekan Enter. Bisa juga klik kanan file di File Explorer, pilih Kirim ke › Urai App.
      2. Atur hasilPilih Satu file per dokumen atau Gabung jadi satu. Untuk gabungan, urutan isi mengikuti daftar; seret pegangan titik-titik untuk memindahkan. Pilih cara membaca scan: Mati, Offline (gratis, di komputer ini), atau AI (lebih akurat, memakai API key Anda).
      3. Tekan tombol biruAtau Ctrl + Enter. File .md tersimpan di folder pilihan Anda. Dari panel hasil, buka file, salin teks, atau buat Mind map dari isinya.
      Tips
      • File Markdown (.md) cocok diunggah ke ChatGPT, Claude, Gemini, atau NotebookLM. Ukurannya jauh lebih kecil dari PDF dan isinya lebih mudah dibaca AI.
      • PDF hasil scan dikenali otomatis dan diberi label. Untuk scan buram atau foto dari HP, pilih Ketelitian Teliti di Pengaturan.
      • Mind map: Struktur dokumen gratis dan offline, cocok untuk Word dan PowerPoint yang punya judul dan subjudul. Rangkuman AI lebih ringkas dan punya jenis Umum, Notulen, dan Laporan. Rangkuman AI bisa keliru, selalu periksa kembali.
      • Link YouTube (Eksperimental): hanya video yang punya subtitle atau transkrip. Transkrip bahasa Indonesia diambil lebih dulu, lalu bahasa Inggris.
      • Rekaman suara (Eksperimental): rekaman dikirim ke layanan pengenal suara Google, bahasa Indonesia. File WAV langsung bisa. MP3 dan M4A butuh FFmpeg terpasang di komputer.
      • Ada masalah? Kirim email beserta file catatan dari folder %APPDATA%\UraiApp\logs. Isi dokumen Anda tidak tercatat di sana.
